# QONYS — Қазақстанның ішкі көші-қоны

Қазақ тіліндегі дипломдық зерттеу сайты: өңірлік карта, көші-қон динамикасы, санақ деректерінің модельдері, кеңістіктік диагностика және шартты болжам. Дизайн мемлекеттік статистика порталдарына тән айқын құрылым мен кестелерді қолданады. Бұл мемлекеттік ресми сайт емес.

**Әдепкі деректер — stat.gov.kz-тен алынған ресми статистика:** 2016–2025, 20 өңір, 200 бақылау. Ішкі көші-қонның келуі, кетуі және сальдосы, сондай-ақ халықтың орташа жылдық саны туралы 4 XLSX түпнұсқасы `data/raw/` ішінде сақталған. ҰСБ метадерегі бұл қатарлардың 2009 жылдан бастап қазіргі өңірлерге сәйкес қайта есептелгенін растайды. Біздің тексерулер барлық өңірлік сомалар мен сальдолардың ресми кестелерге тең екенін растады. Деректер, дереккөз URL-дері, жарияланған күндер және SHA-256 `data/official-metadata.json` ішінде.

`data/demo.csv` — бөлек, анық белгіленген жасанды көрсетілім жиыны; сайт оны әдепкіде қолданбайды. Импортталған пайдаланушы деректерінің түпнұсқаға сәйкестігі автоматты расталмайды.

**Негізгі нәтиже:** 2025 жылы 1 715 597 ішкі келу оқиғасы есептелген (+13,59% жылдық өзгеріс). Ең жоғары оң сальдо — Астана: +87 459. 2025 жылғы тексеруде өткен жыл деңгейін қайталайтын база барлық үш регрессиядан дәлірек; болжамдар осы шектеумен көрсетіледі. Толық есеп: [ANALYSIS.md](ANALYSIS.md).

## Іске қосу

Дайындалған ортада:

```bash
cd /workspace/python
/workspace/python-env/bin/python app.py
```

Сервердің порты — `8000`; оны `PORT` айнымалысымен ауыстыруға болады. Сервер интерфейсі `0.0.0.0`, сондықтан ортаның қолдау көрсетілетін порт бағыттауы арқылы ашылады. Бұл Flask әзірлеу сервері; сыртқы жариялау алдында өндірістік WSGI серверін және HTTPS орнатыңыз.

Жаңа машинада Python 3.12 және виртуалды орта қолданыңыз:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Браузердің сыртқы CDN-ге қосылуы қажет емес: JavaScript, CSS және карта геометриясы жоба ішінде. Сайттың stat.gov.kz-ке сұрауы тек «Ресми дереккөзді тексеру» батырмасы басылғанда орындалады.

## Сайт мүмкіндіктері

- Жыл мен өңір сүзгісі; келгендер, кеткендер, сальдо, 1000 тұрғынға келу көрсеткіші.
- Қазақстан контуры және 20 өңірдің шартты өкілдік нүктелері; нүктені басу өңірді таңдайды.
- Динамика, өңірлер рейтингі, іздеуі бар кесте және автоматты сипаттамалық талдау.
- Пуассон, NB2 және кеңістіктік NB2; өткен жылды қайталайтын базалық болжаммен салыстыру.
- Moran’s I, 999 кездейсоқ ауыстыру, қалдықтардың кеңістіктік диагностикасы, W матрицасын жүктеу.
- 1–5 жылға болжам; шартты 95% болжам аралығы; коэффициенттер, стандарт қателері, p-мәндері.
- CSV импорты және деректер мен болжам нәтижелерін CSV экспорты. Болжам файлында дерек мәртебесі мен дереккөз сақталады.

## Ресми деректер және жаңарту

Әдепкі CSV — `data/official.csv`. Қайта жүктеу және өңдеу:

```bash
/workspace/python-env/bin/python scripts/import_official.py --refresh
```

Скрипт HTTPS тексеруін сақтайды; төрт түпнұсқа файлды алады; индикатор кодтарын, қайта есептеу туралы метадеректі, 20 өңірді, ресми ұлттық сомаларды және `келгендер − кеткендер = ресми сальдо` теңдігін тексереді. Барлық тексеру өтсе ғана нормаланған CSV мен шығу тегі файлы жазылады. «Барлық халық» блогы алынады: қала/ауыл мен ер/әйел ішкі жиындары қайта қосылмайды. Көрсеткіштер санақ емес, **ішкі көші-қонның есепке алынған келу/кету саны**; бірегей адамдар саны деп түсіндіруге болмайды.

Халықтың орташа жылдық санының бөлшек `.5` мәндері сақталады. Оның кесте парағында «жыл басына» және 611101 деген қайшы жазулар бар; файл атауы, 611104 метадерек коды және «жыл басы мен соңының арифметикалық ортасы» анықтамасы басшылыққа алынды. Осы сәйкессіздік сайтта да ашық көрсетілген.

Желіде `stat.gov.kz` рұқсат етілуі қажет; домен орта конфигурациясына қосылған және жүктеу тексерілген. Ағымдағы орта кейін рұқсатты жоғалтса, сайт жергілікті тексерілген көшірмемен жұмысын жалғастырады. «Ресми дереккөзді тексеру» батырмасы жаңа кесте сілтемелерін көрсетеді; дайын есептерді үнсіз өзгертпейді. Жаңартқаннан кейін серверді қайта іске қосып, тексерулерді қайталаңыз.

Қосымша CSV импорттау:

1. ҰСБ [демография динамикалық кестелерінен](https://stat.gov.kz/industries/social-statistics/demography/dynamic-tables/) жылдық **ішкі** көші-қон мен жылдық орташа халықты алыңыз. Сыртқы көші-қонды, айлық аралық қорытындыларды және жылдық деректерді араластырмаңыз.
2. CSV бағандары: `year,region_id,population,arrivals,departures`. Әр жол — бір өңір және бір жыл. UTF-8, үтір/нүктелі үтір. Келу/кету бүтін теріс емес сандар, халық саны оң шекті сан болуы керек; жылдық орташа халық бөлшек болуы мүмкін. Бос мәндер және қайталанған жолдар қабылданбайды.
3. Кемінде 4 қатарлас толық жыл және әр жылда 20 өңір. Жаңа облыстар үшін тарихи деректі нөлмен толтырмаңыз. Сайттың ресми жиыны ҰСБ-ның салыстырмалы қайта есептеген қатарын пайдаланады; басқа файлда осы қасиет бөлек тексерілуі керек.
4. «Дерек жүктеу» терезесінде файлды, нақты дереккөз сілтемесі/кесте атауын енгізіп, аумақтық салыстырмалылықты растаңыз. Импорттан кейін есептер қайта есептеледі. «ҰСБ ресми деректеріне оралу» батырмасы тексерілген бастапқы жиынды қайта ашады.

Импорттар Git-ке кірмейтін `instance/` ішінде сақталады. Дерек жиынының нормаланған CSV SHA-256 сомасы метадеректе сақталады; бұл тұтастықты белгілейді, ресмилікті растамайды. Осы жергілікті сайтта пайдаланушы аутентификациясы жоқ. Жеке немесе құпия микродеректерді жүктемеңіз; тек өңірлік агрегаттармен жұмыс істеңіз.

## Модель және тексеру әдісі

`Y_it` — өңірге келгендердің саны. Пуассон үшін `Var(Y)=mu`; NB2 үшін `Var(Y)=mu+alpha*mu²`. NB2 дисперсиясының alpha параметрі бастапқы Пуассон бағалауының қалдықтары арқылы моменттер әдісімен бағаланады; бұл alpha үшін бірлескен MLE емес. Коэффициенттердің HC1 стандарт қателері alpha бағасының белгісіздігін толық ескермейді.

Барлық модельдерде өңірлердің 19 индикаторы, тұрақты мүше, сызықтық жыл тренді және `log(population)` offset-і бар. Кеңістіктік нұсқа қосымша `log(1 + W @ previous_year_arrivals_per_1000)` белгісін қолданады. Бұл — кеңістіктік лагы бар санау регрессиясы; SAR ықтималдық моделі немесе себеп-салдар бағалауы емес.

`W` Haversine қашықтығымен 2–6 жақын өкілдік нүкте бойынша құрылады. Байланыстар симметрияланады, содан кейін әр жол қосындысы бірге келтіріледі. Осыдан нақты байланыстар саны k-дан көп болуы мүмкін, ал соңғы салмақтар өздері симметриялы болмауы мүмкін. Нүктелер облыстардың ресми центроидтары емес; сезімталдықты k арқылы тексеріңіз. Облыстардың ортақ шекара матрицасы қолданылмайды.

Әдістерді әділ салыстыру үшін бірінші жыл барлық модельдерден алынып тасталады: ол кеңістіктік лагты жасауға керек. Соңғы толық жыл модельдерді үйретуге кірмейді. MAE/RMSE/WAPE — осы жылдағы 20 өңір бойынша қателер. Тексеру сол жылғы белгілі халық санына шартты. Өткен жыл мәнін қайталайтын қарапайым болжам міндетті салыстыру ретінде беріледі. Ең төмен қате моделі кеңістіктік модель болмауы мүмкін.

Кейін таңдалған модель барлық қолжетімді жылдарда қайта бағаланып, болжам жасалады. Халық саны соңғы жылғы деңгейде тұрақты. Seed=2841, 1200 траекториямен болашақ санаулар симуляцияланады; кеңістіктік лаг алдыңғы симуляция қадамы арқылы жаңартылады. Ұлттық интервалдар өңірлік шектерді қосумен емес, әр траекториядағы өңірлерді қосып, квантиль алу арқылы есептеледі. 95% шартты интервал коэффициенттер мен демографиялық сценарийдің белгісіздігін қамтымайды. Симуляция өңірлік инновацияларды шартты тәуелсіз деп алады; ескерілмеген бірлескен шоктар аралықтарды тарылтуы мүмкін.

Moran’s I әр жылғы 1000 тұрғынға келу қарқынына және соңғы жылғы таңдалған модельдің Pearson қалдықтарына есептеледі. Екіжақты permutation p-мәні `|I - E(I)|` бойынша, 999 ауыстырумен және seed=417 арқылы алынады. Бұл көп жылға арналған бірлескен маңыздылық түзетуі емес. HC1 стандарт қателері уақыттық/кеңістіктік қалдық корреляциясын толық түзетпейді. Экономикалық факторлар жоқ, сондықтан себептілік туралы тұжырым жасалмайды.

## Тексеру

```bash
/workspace/python-env/bin/python -m pip install -r requirements-dev.txt
/workspace/python-env/bin/python -m pytest -q
# Сервер бөлек іске қосылып тұруы керек; Chromium: /usr/bin/chromium
/workspace/python-env/bin/python scripts/browser_check.py
```

Unit/API тесттері: дерек толықтығы, дұрыс уақыттық лаг, тест жылының оқытуға өтпеуі, W қасиеттері, Moran анықтамасы, болжам қосындылары/аралықтары, API валидациясы және ресми көзге қолжетімділік болмағандағы мәртебе.

Браузер тексеруі: компьютер/телефон, карта, өңір/жыл сүзгілері, модель/көкжиек, CSV жүктеу/импорт, қате файлдар, диалогтер және JavaScript қателері. Скриншоттар `artifacts/` ішінде.

Бастапқы Jupyter-блокнот өзгертілмеген; оның өзіне қажет `data.csv` пен `wee.csv` бұл көші-қон сайтына қатысы жоқ.

## Файлдар

- `app.py` — Flask және JSON API.
- `analytics.py` — валидация, модельдер, уақыттық тексеру, Moran’s I және болжам.
- `sources.py`, `scripts/import_official.py` — ресми кестелерді табу, жүктеу және тексеру.
- `data/official.csv`, `data/official-metadata.json`, `data/raw/` — ресми деректер және олардың шығу тегі.
- `templates/index.html`, `static/` — қазақша интерфейс, жергілікті SVG графиктер.
- `data/demo.csv`, `scripts/generate_demo.py` — анық белгіленген жасанды мысал.
- `data/regions.json` — 20 өңірдің атауы және шартты өкілдік координаталары.

Карта контуры: [datasets/geo-countries](https://github.com/datasets/geo-countries), Natural Earth негізінде, Open Data Commons PDDL 1.0 / public domain. Ел контуры ғана көрсетіледі; әкімшілік шекаралардың нақты талдауы үшін ресми және жылға сәйкес геодеректер керек.
